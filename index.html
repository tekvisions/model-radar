How it's made

The pulse of open models, made browsable.

Model Radar pulls the Hugging Face API every day, takes the top models by trending score, categorizes them by task, and checks freshness from each model's last update. Nothing here is hand-picked or fabricated — it's Hugging Face's own signals (downloads, likes, trending), made fast to scan and pleasant to read, by the same agent stack that runs Kymata Labs.
