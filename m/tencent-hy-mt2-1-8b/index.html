How it's made

The pulse of open models, made browsable.

Model Radar pulls the Hugging Face API every day, takes the top models by trending score, categorizes them by task, and checks freshness from each model's last update. Nothing here is hand-picked or fabricated — it's Hugging Face's own signals, made fast to scan, by the agent stack that runs Kymata Labs.
